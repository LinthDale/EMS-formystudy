## 摘要

本文提出一套適用於 100 kWh 級磷酸鐵鋰（Lithium Iron Phosphate, LFP）電池儲能系統（Battery Energy Storage System, BESS）的電池管理系統（Battery Management System, BMS）設計。電池簇採 1P96S 或 1P112S 組態，由 6 或 7 片 16S 電池監測單元（Battery Monitoring Unit, BMU）與 1 台電池控制單元（Battery Control Unit, BCU）構成兩層式架構。BMU 負責單體電壓、溫度、開線診斷與均衡控制；BCU 負責荷電狀態、健康狀態、動態充放電能力估算，以及預充、接觸器、絕緣與故障狀態管理。

設計內容涵蓋量測精度與時序、狀態估算、分級保護、均衡、高壓箱、對外通訊、資料記錄、電源與環境條件，以及需求追溯與設計驗證。單體電壓準確度以 ±5 mV、全串更新週期不大於 100 ms 為基準；保護判定、動態限流與高壓切斷均由本地安全層執行。功率轉換系統（Power Conversion System, PCS）在 BMS 發布的充放電能力邊界內運轉，能源管理系統（Energy Management System, EMS）負責監看、資料保存與監督式派工。本規格作為硬體、韌體、演算法與工程樣機設計凍結的共同基準。

## 一、文件定位與使用方式

### 1.1 設計目標

本設計應完成下列閉環：

1. 將 GFL 314 Ah 磷酸鐵鋰（Lithium Iron Phosphate, LFP）電芯限制轉換為量測、估測、降載、方向禁止及跳脫邏輯。
2. 以同一 BMS 硬體及韌體支援 1P96S 與 1P112S，避免因容量方案未凍結而重做平台。
3. 使任何保護動作都能追溯到原始量測、有效性狀態、參數版本、演算法輸出與執行機構回授。
4. 在 EMS 或一般通訊失效時，仍維持本地安全功能並收斂至已定義狀態。
5. 產出可供電路、印刷電路板、韌體、演算法、線束、高壓箱與整合測試共同使用的設計基準。

### 1.2 規範用語

- 「應」：設計發布前必須滿足。
- 「目標」：優先達成；未達成時須提出分析、替代方案與風險核准。
- 「初始值」：供 v0.1 設計與模擬使用，設計凍結前須由受控電芯資料、PCS 介面或計算結果確認。
- 「待核」：缺少設計輸入，不得靜默固化為量產參數。

### 1.3 要求狀態

| 狀態 | 定義 | 設計處置 |
|---|---|---|
| A－已核准 | 已有受控來源或已完成設計決策 | 可進入設計凍結與驗證 |
| P－初步 | 可供 v0.1 實作與分析 | 驗證前須完成假設檢查 |
| T－待確認 | 缺少外部輸入或跨系統決策 | 不得作為量產放行依據 |

| SYS-005 | BMS 失電、重啟或資料無效時，接觸器不得自行回到閉合狀態 | 電源循環與異常復歸測試 |

## 三、系統情境與責任配置

本系統採兩層架構：每個 1P16S 模組配置一片電池監測單元（Battery Monitoring Unit, BMU），單簇配置一台電池控制單元（Battery Control Unit, BCU）。

~~~mermaid
flowchart TB
    C["16S 電芯模組<br/>電壓與溫度"] --> B["BMU × 6 或 7<br/>隔離量測與均衡"]
    B --> M["BCU<br/>狀態估測與安全控制"]
    M --> H["高壓箱<br/>預充 接觸器 熔斷器"]
    M --> P["PCS<br/>限流與功率轉換"]
    M --> E["EMS<br/>監看 記錄 派工"]
    F["硬線與熔斷保護"] --> H
~~~

| 功能 | 設計權威 | EMS 權限 |
|---|---|---|
| 單體過壓／欠壓、過溫、低溫禁充 | BMS 本地 | 唯讀、告警 |
| 允許充電電流／允許放電電流與允許電壓 | BMS 本地 | 唯讀，派工不得超越 |
| 接觸器、預充、黏著檢測 | BMS＋高壓箱 | 可要求啟停，不可直接驅動 |
| PCS 電流迴路、有功／無功與成網控制 | PCS 本地 | 可下達監督式設定值 |
| 短路與極端過流 | 直流熔斷器／硬體保護 | 無 |
| 歷史資料與營運排程 | EMS | 主要執行者 |

設計原則：**BMS 計算電池當下能否充放及最大允許能力；PCS 在該邊界內即時控流；EMS 決定營運目標，但不能改寫安全邊界。**

## 四、架構分解與硬體設計

### 4.1 BMU 設計責任

| ID | 設計要求 |
|---|---|
| HW-101 | 每片 BMU 應管理 16 個單體電壓通道；未使用通道須可受控停用並與開線故障區分。 |
| HW-102 | BMU 應完成單體電壓、模組溫度、感測開線、均衡驅動與板溫監測。 |
| HW-103 | 類比前端（Analog Front End, AFE）、數位隔離、線束及保護元件應納入完整誤差與耐壓分析。 |
| HW-104 | BMU 間通訊應採隔離式 daisy-chain 或隔離控制器區域網路（Controller Area Network, CAN），包含循環冗餘校驗（Cyclic Redundancy Check, CRC）、序號、逾時與節點定位。 |
| HW-105 | 均衡故障、AFE 異常、基準電壓異常及板溫超限應由 BMU 本地停止相關輸出並上報 BCU。 |

### 4.2 BCU 設計責任

| ID | 設計要求 |
|---|---|
| HW-201 | BCU 應管理 6 或 7 片 BMU，並由受控組態定義有效節點、串數及溫度點數。 |
| HW-202 | 簇電壓量測範圍應為 0–500 VDC；建議分別量測電池側及 PCS 直流鏈側。 |
| HW-203 | 簇電流量測範圍應至少 ±500 A，連續工作涵蓋 ±350 A，保護鏈在目標過流點前不得飽和。 |
| HW-204 | BCU 應控制主正、主負與預充驅動，並讀取輔助接點、高壓互鎖及外部安全輸入。 |
| HW-205 | 安全關鍵輸出應採失電跳脫（de-energize-to-trip）；控制器重啟時維持接觸器開啟。 |
| HW-206 | BCU 應具獨立硬體看門狗、電源監控、時鐘監控、非揮發參數完整性檢查及安全啟動策略。 |

### 4.3 電氣隔離與單點故障

- 高壓量測、BMU 通訊、24 V 電源、PCS／EMS 介面之隔離邊界須在系統原理圖中明確標示。
- 任一 BMU 失聯、量測鏈斷線或資料失真時，不得以最後正常值無限期維持運轉。
- 單一軟體程序失效不得使過充、過放或過溫保護全部失效。
- 參數校驗失敗、韌體映像損壞或時鐘異常時，不得靜默載入一般預設值進入 RUN。
- BMS 重啟後須重新完成自檢、絕緣、接觸器合理性及預充流程。

### 5.2 感測器配置

- 每個 16S 模組的溫度點至少覆蓋進風端、出風端、預期熱點及代表性電芯大面。
- 匯流排、熔斷器或接觸器熱點另設溫度監測，不以電芯溫度取代。
- 電流主量測可採高精度分流器加隔離量測；若另設霍爾感測器，須定義其獨立保護或交叉診斷角色。
- 電池側與 PCS 側電壓應可交叉驗證接觸器命令、預充進度及黏著狀態。

### 5.3 資料有效性模型

每一安全關鍵量測值應同時輸出數值、時間戳、品質旗標與來源。品質狀態至少包含 Valid、Stale、Out-of-range、Open-wire、CRC error、Not-configured。

| ID | 設計要求 |
|---|---|
| DATAQ-001 | 任何演算法只可使用 Valid 且未逾時的輸入。 |
| DATAQ-002 | Stale 或 Invalid 不得被限幅成看似正常的數值。 |
| DATAQ-003 | 最大／最小值輸出須同時帶出 BMU、通道與電芯索引。 |
| DATAQ-004 | 單體加總、簇電壓與接觸器兩側電壓應執行合理性檢查。 |
| DATAQ-005 | 感測失效時的 CCL／DCL 與接觸器動作須由故障矩陣明確定義。 |

## 七、SOC、SOH 與動態能力演算法

### 7.1 荷電狀態

荷電狀態（State of Charge, SOC）以庫倫積分為主，搭配有效滿充／滿放端點、靜置開路電壓（Open Circuit Voltage, OCV）及溫度模型修正。

| ID | 設計要求 |
|---|---|
| ALG-101 | 中段 LFP OCV 不得作為唯一 SOC 來源。 |
| ALG-102 | 積分容量應隨已確認的容量 SOH 更新，並保存歷次端點校正紀錄。 |
| ALG-103 | 斷電、實時時鐘失效或更換 BCU 後，應有 SOC 恢復、可信度及再校正狀態。 |
| ALG-104 | SOC 無效時，單體電壓、溫度與硬體保護仍須有效。 |
| ALG-105 | SOC 輸出應包含 estimate、confidence、last calibration 與 invalid reason。 |

### 7.2 健康狀態

健康狀態（State of Health, SOH）至少分為容量 SOH 與內阻 SOH，兩者不得合併為單一不可解釋數值。

- 容量 SOH 由合格參考循環或經核准的線上辨識更新。
- 內阻 SOH 須定義量測方法、溫度／SOC 補償及初始基準。
- 電芯容量、內阻與異常次數須能對應電芯序號、模組序號及更換紀錄。
- 任一電芯達 GFL 壽命終止（End of Life, EOL）條件時，輸出 EOL 狀態、禁止正常服役並保存證據。

### 7.3 動態 CCL／DCL

允許充電電流（Charge Current Limit, CCL）與允許放電電流（Discharge Current Limit, DCL）由各限制器取最小值：

~~~mermaid
flowchart LR
    T["溫度限制"] --> L["最小值選擇<br/>斜率限制"]
    V["單體電壓限制"] --> L
    S["SOC SOH 限制"] --> L
    C["電芯倍率曲線"] --> L
    H["接觸器 熔斷器 線材"] --> L
    P["PCS 系統額定"] --> L
    L --> O["CCL DCL<br/>值 品質 原因碼"]
~~~

| ID | 設計要求 |
|---|---|
| ALG-201 | 0.5C 版本在合格溫度與 SOC 下，CCL／DCL 上限以 157 A 為初始基準。 |
| ALG-202 | 1C 版本在合格溫度與 SOC 下，CCL／DCL 上限以 314 A 為初始基準。 |
| ALG-203 | 正常允許電流不得直接用作過流跳脫值。 |
| ALG-204 | CCL／DCL 變化應具上升／下降斜率、緊急旁路條件與主要限制原因碼。 |
| ALG-205 | PCS 定功率運轉時仍須以 CCL／DCL 夾箝，低電壓不得因維持功率而超流。 |
| ALG-206 | 任一必要輸入無效時，限制器應依故障矩陣輸出保守值或歸零，不可維持最後值。 |

> **【待核】** GFL 的溫度／SOC 連續與脈衝倍率表須轉為受版本控制的查表或演算法；-30～-20°C 放電截止與倍率須取得書面輸入。

## 八、保護概念與安全狀態機

### 8.1 保護等級

| 等級 | 名稱 | 系統動作 |
|---|---|---|
| L1 | 告警 | 記錄、上報，可維持運轉 |
| L2 | 降載 | 動態降低 CCL／DCL，要求 PCS 平滑降功率 |
| L3 | 方向禁止 | CCL 或 DCL 歸零，禁止充電或放電 |
| L4 | 緊急跳脫 | PCS 停流、開接觸器、鎖定故障；極端事件走硬體切斷 |

每一保護項目都應在故障矩陣中定義：來源訊號、有效性需求、門檻、延遲、遲滯、動作、回復條件、鎖定、復歸權限、故障碼及事件資料。

### 8.2 初始電壓與溫度設計

| 保護項目 | 初始設定 | 動作 | 設計說明 |
|---|---:|---|---|
| 單體高壓預警 | 3.55–3.60 V | L1／L2 | 進入 CCL 降載區 |
| 單體充電禁止 | 名義設定須保證實際 ≤3.65 V | L3 | 納入 ±5 mV、時序與 PCS 過衝 |
| 持續過壓且仍有充電電流 | 實際達 3.65 V | L4 | 處理 PCS 不服從或通訊失效 |
| 單體低壓預警 | 2.80 V | L1／L2 | DCL 漸進降低 |
| 單體放電禁止 | 2.60 V | L3 | 保留誤差及放電慣性 |
| 單體絕對低壓 | >0°C 不得低於 2.50 V | L4 | 低溫 2.00 V 條件不得作為日常工作點 |
| 低溫充電 | 任一有效溫度 <0°C | L3 | 回復需遲滯與穩定時間 |
| 高溫降載 | >45°C | L2 | 依最高有效電芯溫度 |
| 高溫停止充放 | ≥55°C | L3 | v0.1 保守設計值 |
| 絕對操作溫度 | ≥60°C | L4 | 停止充放並進入故障處置 |
| 最終高溫關機 | ≥65°C | L4 鎖定 | 人工檢查後復歸 |
| 模組／簇溫差 | >8°C／>12°C | L1／L2 | 風道、感測或連接異常 |

### 8.3 電流、絕緣與系統故障

| 故障 | 判定設計 | 安全動作 |
|---|---|---|
| 連續過流 | 依當下 CCL／DCL、溫度、SOC 及延遲曲線 | 降載或方向禁止 |
| 瞬時過流 | 與 PCS 脈衝、接觸器分斷及熔斷器曲線協調 | 快速禁止；必要時開接觸器 |
| 短路 | 最大預期短路電流與直流分斷能力 | 硬體切斷，不依賴 EMS／一般 CAN |
| 絕緣下降 | 1 MΩ 告警／500 kΩ 跳脫初始值 | 告警、停流及跳脫 |
| BMU 失聯／CRC 持續錯誤 | 節點資料無效 | 受控停流後開接觸器 |
| 單體感測開線 | 定位到通道及模組 | 禁止相關方向或停機 |
| 電流感測失效 | 不一致、飽和、零點或合理性異常 | CCL／DCL 歸零；必要時跳脫 |
| 接觸器黏著／拒動 | 輔助接點＋兩側電壓交叉判定 | 鎖定故障，禁止再預充 |
| 充電逾時 | 累計充電超過 8 h | 停止充電並標記異常終止 |
| 消防／緊急停止 | 常閉硬線或安全迴路動作 | 立即進入定義的緊急安全態 |

> **【待核】** 過流延遲／瞬時數值與熔斷器選型須在 PCS 型號、電芯脈衝倍率、線材、接觸器及最大短路電流確定後完成選擇性協調。

## 九、均衡子系統設計

314 Ah 電芯的均衡設計以可達成的修正能力與熱負荷為核心，不只以主動或被動拓撲分類。

| ID | 設計要求 |
|---|---|
| BAL-101 | 在定義的 SOC、溫度與可用時窗下，1% SOC 差異（3.14 Ah）應於 12 h 內修正至目標範圍。 |
| BAL-102 | 被動均衡參考電流應 ≥300 mA；若低於此值，須以實際使用情境證明仍達 BAL-101。 |
| BAL-103 | 主動均衡若採 1–5 A，須定義效率、能量方向、故障隔離、待機功耗及失效安全。 |
| BAL-104 | 啟動條件應包含高 SOC、低充電電流、充電尾段或經確認的靜置狀態。 |
| BAL-105 | 判定應使用單體壓差、工作狀態及資料品質，不依賴 LFP 中段 OCV。 |
| BAL-106 | 停止條件應包含目標壓差、SOC／電流區、電芯溫度、BMU 板溫及均衡故障。 |
| BAL-107 | 應記錄每通道均衡狀態、累計時間、估算電荷量、板溫及異常。 |

300 mA 修正 1% SOC 的理想時間約 10.5 h；設計須額外納入 duty cycle、電阻容差、電壓變化與熱降額。100 mA 的理想時間約 31.4 h，不適合作為本案預設設計。

> **【設計決策】** v0.1 先以「≥300 mA 被動均衡＋12 h 修正能力」建立硬體及熱分析；若使用情境無法提供足夠高 SOC 時窗，再升級為主動均衡方案。

## 十、高壓箱、預充與接觸器控制

### 10.1 高壓箱邊界

高壓（High Voltage, HV）箱由 BMS 控制，至少包含：

- 主正／主負接觸器及輔助接點。
- 預充接觸器／繼電器與預充電阻。
- 直流熔斷器。
- 維修斷開裝置（Manual Service Disconnect, MSD）。
- 高壓互鎖迴路（High Voltage Interlock Loop, HVIL）。
- 電流感測器、電池側／PCS 側電壓量測。
- 絕緣監測裝置（Insulation Monitoring Device, IMD）介面。

接觸器與熔斷器的額定電壓、連續電流、分斷能力、溫升、壽命及 I²t 應由最壞電壓、1C 連續 314 A、環境溫度、櫃內溫升、PCS 直流鏈及最大短路電流共同決定；「400 A 級」只作 v0.1 尺寸估算。

### 10.2 狀態機

~~~mermaid
stateDiagram-v2
    [*] --> OFF
    OFF --> SELFTEST: 喚醒
    SELFTEST --> PRECHARGE: 自檢 絕緣 組態合格
    PRECHARGE --> RUN: 電壓比與電流達標
    PRECHARGE --> FAULT: 逾時 電流異常 過熱
    RUN --> OFF: 正常停流
    RUN --> FAULT: L4 或執行機構失效
    FAULT --> OFF: 人工復歸後重新自檢
~~~

| ID | 設計要求 |
|---|---|
| HV-101 | OFF 狀態應維持所有主接觸器釋放並監測異常帶電。 |
| HV-102 | SELFTEST 應檢查組態、BMU 健康、量測合理性、絕緣、HVIL、接觸器狀態與外部安全輸入。 |
| HV-103 | 預充電阻應依 PCS 直流鏈電容量、初始壓差、目標時間、單次能量、重複週期及最壞溫度選型。 |
| HV-104 | 預充成功初始判據為 PCS 側電壓達電池側 90–95%，且預充電流低於門檻。 |
| HV-105 | 預充須有最大時間、最短重試間隔與最大重試次數，禁止無限重試。 |
| HV-106 | 正常停機應先要求 PCS 電流歸零，確認低於安全門檻後再開接觸器。 |
| HV-107 | 接觸器命令、輔助接點與兩側電壓應進行黏著／拒動交叉診斷。 |
| HV-108 | 系統應定義直流鏈放電至安全電壓的路徑、時間及診斷方式。 |

## 十一、對外介面與失效安全

### 11.1 BMS↔PCS

| ID | 設計要求 |
|---|---|
| IF-101 | 實體層採隔離 CAN 2.0B；位元率、終端及拓撲於 PCS 確定後凍結。 |
| IF-102 | CCL、DCL、允許電壓、enable、SOC、簇 V／I 與故障狀態週期應 ≤100 ms。 |
| IF-103 | 訊息應包含 CRC／checksum、alive counter、rolling counter、版本及無效值定義。 |
| IF-104 | 介面定義以受版本控制的 CAN 資料庫檔（DBC）或等效文件管理。 |
| IF-105 | 至少提供一組常閉、失電跳脫的 PCS permissive／battery trip 硬線。 |

必要訊號至少包含 CCL、DCL、最大允許充電電壓、最小允許放電電壓、SOC、SOH、簇 V／I、單體最大／最小電壓、最高／最低溫度、接觸器狀態、資料品質及故障碼。

BMS↔PCS 失聯處置：

1. 連續 3–5 個即時週期遺失或資料無效時，PCS 將允許功率平滑降至零。
2. 失聯持續超過設定時間，BMS 在確認安全停流後開接觸器。
3. 同時發生過壓、短路、消防或其他 L4 故障時，不等待通訊恢復。

### 11.2 BMS↔EMS

- 優先採 Modbus TCP；若使用 CAN 或閘道器，須提供完整暫存器／訊息表。
- EMS 可讀取全單體電壓、全部溫度、簇 V／I、SOC、SOH、CCL／DCL、絕緣、均衡、接觸器、告警及故障。
- 安全參數、校正值、接觸器直接控制及故障旁路預設不可由 EMS 寫入。
- 遠端復歸若開放，須有角色授權、事件稽核、現場條件檢查及不可復歸故障清單。
- EMS 失聯不等於 BMS 失聯；BMS 應維持安全監測，運轉策略由 PCS／本地控制器依系統模式處理。

### 11.3 外部安全介面

消防、煙霧、可燃氣體、緊急停止（Emergency Power Off, EPO）與 HVIL 應具硬線安全路徑。常閉安全迴路斷線視同動作，且須能診斷回路狀態。外部 EPO 與一般 BMS 故障使用不同故障碼與復歸程序。

## 十三、電源、環境、可靠度與功能安全輸入

### 13.1 24 V 與長期停機

- 優先使用受監控的外部 24 VDC 輔助電源，並定義工作範圍、突波、反接與 brownout 行為。
- 若任何電源由高壓電池取得，deep-sleep 等效簇電流目標 ≤2 mA，並由 SOC、靜置時間及自放電推導安全停機期限。
- 接觸器釋放後不得保留不必要的線圈功耗。
- 支援喚醒輸入、排程喚醒及維護喚醒，避免反覆重啟耗盡電池。
- 預計靜置超過 30 天時，依核准電芯條件建立 SOC 維護與提醒策略。

### 13.2 環境與可靠度

| 項目 | 初始設計要求 |

| BMS 電子元件工作溫度 | 至少 -30～70°C，完成元件降額 |

| 濕度 | 5–95% RH、無凝露；配合櫃體防凝露 |

| 連接器 | 防呆、鎖固、端子保持力與維修防誤插 |
| 電磁相容性 | 工業環境抗擾度／發射；干擾下安全功能不得失效 |
| 振動／衝擊 | 依運輸、安裝位置與風扇振動條件 |
| 設計壽命 | 與電池系統一致；關鍵元件壽命與降額可追溯 |

## 十七、設計結論與下一個設計閘門

本 BMS 採 6／7 片 16S BMU 加一台 BCU 的兩層平台，以受控組態支援 1P96S 與 1P112S。設計核心不是單一過壓或欠壓數字，而是形成「量測有效性 → 狀態估測 → 動態限制 → 保護決策 → 高壓執行 → 回授診斷 → 事件追溯」的完整閉環。

下一個系統設計閘門應完成：

1. 凍結電芯受控規格、96S／112S 與 0.5C／1C 產品組態。
2. 凍結 PCS 直流窗、CAN 協定、直流鏈電容及停流行為。
3. 完成量測誤差預算、預充、短路、熔斷器、接觸器與熱分析。
4. 完成 SOC／SOH／CCL／DCL 演算法規格及限制表版本。
5. 發布故障矩陣、狀態機、介面控制文件與 DVP&R v0.1。
6. 核准功能安全及法規路徑，建立要求追溯與配置基線。

完成上述輸出後，才進入工程樣機設計凍結；後續 BESS 系統整合與案場交付驗證由獨立整合計畫承接。
